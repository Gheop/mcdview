mcdview — example models

Interactive HTML explorers generated by mcdview from plain DDL files. Click a table to isolate it with its related tables.

  • Médiathèque — fictional French library (12 tables, 3 schemas, audit FKs)
  • Pagila — DVD rental store (16 tables, partitioned payments)
  • Northwind — the historic trading company sample (14 tables)
  • Chinook — digital music store (11 tables)
  • Schema diff — a shop model compared across two versions (--diff): added, removed and changed tables, columns and FKs colored, with a "touched only" filter
Pages rebuilt by CI on every push — source on GitHub.
